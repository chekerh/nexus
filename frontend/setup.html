🎬 YouTube Setup
  1. Go to Google Cloud Console
  2. Create a new project or select existing
  3. Enable YouTube Data API v3
  4. Go to Credentials → Create Credentials → OAuth 2.0 Client ID
  5. Application type: Web application
  6. Add redirect URI: https://developers.google.com/oauthplayground
  7. Copy Client ID and Client Secret to your .env file
  8. Go to OAuth Playground
  9. Click gear icon → check "Use your own OAuth credentials" → paste Client ID and Secret
  10. In scopes, enter: https://www.googleapis.com/auth/youtube.upload → Authorize APIs
  11. Click Exchange authorization code for tokens
  12. Copy the Refresh token — paste it as SYSTEM_YOUTUBE_REFRESH_TOKEN in .env
YouTube client configured: check .env
📱 TikTok Setup
  1. Go to TikTok Developer Portal
  2. Create a new app with Login Kit and Content Posting permissions
  3. Add redirect URI: https://your-domain.com/api/v1/oauth/tiktok/callback
  4. Copy Client Key and Client Secret to .env
  5. After OAuth flow, you'll get an access token and refresh token
  6. Set SYSTEM_TIKTOK_ACCESS_TOKEN and SYSTEM_TIKTOK_REFRESH_TOKEN in .env
  7. Required: Set PUBLIC_BASE_URL to your server's public URL
Requires TikTok developer account
📸 Instagram Setup
  1. Go to Facebook Developers
  2. Create a new app with Instagram Graph API
  3. Convert your Instagram account to a Business/Creator account
  4. Connect your Instagram account in the Facebook App dashboard
  5. Generate a User Access Token with instagram_basic, instagram_content_publish scopes
  6. Paste the token as SYSTEM_INSTAGRAM_ACCESS_TOKEN in .env
  7. Find your Instagram User ID and set SYSTEM_INSTAGRAM_USER_ID
🐦 X/Twitter Setup
  1. Go to Twitter Developer Portal
  2. Create a new project and app with OAuth 2.0
  3. Enable Read and Write permissions
  4. Copy Client ID and Client Secret to .env
  5. Generate a token with tweet.read tweet.write users.read offline.access scopes
  6. Set SYSTEM_TWITTER_ACCESS_TOKEN in .env
